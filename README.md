## About EronX Tweaks
[English](/README.md)

**EronX Tweaks** is a dynamic Magisk module designed to maximize your device's gaming performance while intelligently preserving battery life during everyday use. Perfect for gamers who demand smooth gameplay without compromising daily usability!

More info about this project on [Official Encore Tweaks website](https://encore.rem01gaming.dev/)

## Supported Root Managers

- [APatch](https://github.com/bmax121/APatch)
- [KernelSU](https://github.com/tiann/KernelSU)
